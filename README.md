# Scratch 编程课练习平台

站前小学 Scratch 编程社团的课后练习平台：学生登录、选择题练习（单选+多选）、自动出分、错题本。

## 说明

- `index.html` 是整个网站（单文件 SPA，无需构建）
- 学生登录：输入中文姓名或拼音，初始密码 `123456`
- 答题记录保存在学生各自浏览器的 localStorage 中，更新网站不影响已有记录

## 部署

仓库连接 Netlify 自动部署，访问地址：**https://scratch.aizqxx.top**

更新方式：直接修改并推送到本仓库，Netlify 约 1 分钟内自动上线。
